# 2_音标学习 — KK 音标学习 App（周育如课程体系）

> 以 ralph 并行循环持续迭代中：功能开发 + 定时续跑（至 **08:30**）。任务看板见 [tasks/](tasks/)。

## 功能总览（7 个 Tab）

| Tab | 内容 |
|---|---|
| 🏠 首页 | 早晚打卡、每日一句（英+中点读）、进度总览、六大板块直达卡、七天计划 |
| 📣 口诀 | 26 字母卡片墙 + 2+2 跟读；三根滑条精确控制停顿（字母间隔/音标间隔/叠字间隔，0 秒=真连读「BB啵啵」） |
| 📖 规则 | 五大规则课程卡；正文里的 /eɪ/ /ɝ/ 等音标可点读本音；规则 5 组合表（字母 → 本音 → 例词三段点读） |
| 📚 阅读 | 内置 6 篇原创分级短文（含参考译文 + 词表）；粘贴任意英文文章；点句朗读逐句高亮；点词查义自动进生词本；生词本（听读/手动加词/听写挑战）；自定义文章在线翻译（MyMemory，免密钥） |
| ✍️ 写作 | 10 个原创写作模板（结构句式可点读 + 范文中英对照）→ 分段引导仿写器（句式点插、实时词数、自查清单）→ 作品管理（续写/朗读/删除） |
| ✏️ 练习 | 看词选音标 / 听音选词 / 判断规则 + 每日一测；错题自动进错题本 |
| 📅 复习 | 早晚打卡、14 天日历、连续天数、错题本、KK/IPA 对照表 |

- **音标本音**：44 个 KK 音标全部带离线本音录音（Windows SAPI 合成；`app/scripts/gen-phoneme-audio.mjs` 可用 Azure 神经语音升级为 mp3，播放层自动优先）
- **发音**：全部经 `app/src/hooks/useSpeech.ts` 统一出口；口诀/联想字用打包的神经语音录音，音标本音用预合成音频
- **深色模式**：跟随系统，全站适配

## 运行应用

```bash
cd app
npm install   # 首次
npm run dev   # http://localhost:5173
```

构建验收：`cd app && npm run build`

安卓打包（Capacitor 8）：见 [PACKAGING.md](PACKAGING.md)，产物 `app/android/app/build/outputs/apk/debug/app-debug.apk`。

周育如音标课核心笔记（KK 音标版），整理自网络公开的学习者记录。核心框架：一个口诀（26 字母常见发音）+ 五个规则。阅读短文与写作范文均为本项目原创编写。
